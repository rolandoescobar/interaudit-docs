# Changelog

Este registro sigue la idea de **Keep a Changelog** y versiones estilo **SemVer** cuando corresponda.  
Cada entrada incluye **Fecha (AAAA-MM-DD)**, **Tipo** (*Added, Changed, Fixed, Docs, Breaking*), y notas de **migración** si aplica.

## Cómo registrar un cambio
1. Crea una rama `feat/...` o `fix/...`.
2. Actualiza este archivo en la sección **[Unreleased](#unreleased)**.
3. Si vas a publicar una “versión”, mueve los ítems a una nueva sección con fecha.
4. Abre PR usando **Conventional Commits** y el checklist del repo.
