description: Qué muestra cada tarjeta del Escritorio, cómo se interpreta y a qué vista te lleva.
---

El **Escritorio** concentra tarjetas con conteos clave y accesos rápidos. Todas las cifras se filtran por tu
**organización activa** y por tus **permisos**.

## Cómo leer las tarjetas
- **Título**: dominio (Normas, Controles, Requisitos, etc.).
- **Valor**: conteo actual visible para ti.
- **Enlace**: abre el listado correspondiente ya filtrado (cuando aplica).

## Tarjetas
- **Normas** → *Normativa → Requisitos*  
- **Normas certificables** → *Requisitos* filtrados por certificables  
- **Requisitos** → *Normativa → Requisitos*  
- **Controles** → *Normativa → Controles & SoA*  
- **Organizaciones** → *Organización → Estructura*  
- **Proyectos** → *Proyectos → Plan*  
- **Mapeos** → *Normativa → Mapeos y aplicabilidad*  
- **Tickets abiertos/cerrados** → *Soporte → Tickets*

:::note
Si un número no coincide con lo esperado, revisa **organización activa**, **filtros** del listado y **permisos**.
:::
